ประเภทกลุ่ม 4 คน

  • แก๊งยายชุดบ้าน — เสื้อคอกระเช้า + ผ้าถุง / กางเกงลายดอก + ยาดม + ผ้าขนหนูพาดบ่า
  • แก๊งกางเกงช้าง — กางเกงช้างคนละสี + เสื้อยืดตลาดนัด
  • แก๊งนอนค้างบ้านเพื่อน — เสื้อยืดขาวชุดเดียวกัน + หมอน + ผ้าห่มลายเสือ

ประเภทเดี่ยวชาย

  • ลุงบ้านสวน — เสื้อกล้ามขาว + ผ้าขาวม้านุ่งโสร่ง + พัดสาน
  • เสี่ยชุดนอน — ชุดซาติน/ผ้าไหมลายไทย + สร้อยทอง (ปลอม) + แว่นดำ
  • หนุ่มตลาดนัด — กางเกงช้าง + เสื้อลายการ์ตูน + รองเท้าแตะ

ประเภทเดี่ยวหญิง

  • คุณนายชุดนอน — ชุดลายดอก + โรลม้วนผม + ครีมพอกหน้า
  • สาวหวานสายชิล — ชุดนอนพาสเทล + สลิปเปอร์ขนฟู + ตุ๊กตาหมี
  • แม่หญิงนอนหลับ — ผ้าถุง + เสื้อคอกระเช้า + ผ้าปิดตา
